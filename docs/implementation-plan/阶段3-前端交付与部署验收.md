# 阶段3：前端交付与部署验收

> 状态：待实施  
> 前置阶段：阶段1、阶段2均已验收  
> 依据：[飞书机器人跟催-冻结实施方案](飞书机器人跟催-冻结实施方案.md)  
> 阶段边界：本阶段完成用户界面、可观测性、容器部署和最终验收，不新增业务能力。

## 1. 阶段目标

在已完成的数据预览和可靠发送能力之上，交付可供TPM使用的简易内网页面，完善日志、指标、告警、Docker部署、安全校验和验收材料，达到一期上线条件。

## 2. 前置检查

开始本阶段前必须确认：

- 阶段1和阶段2均已验收并留有工作日志；
- 预览、发送、查询和失败重试API契约已经稳定；
- 已完成机器人消息卡片联调；
- 内网网关、Redis、日志平台和密钥注入方案可用；
- 用于最终验证的脱敏测试表和测试账号已准备好。

## 3. 实施范围

### 3.1 简易前端

- 使用Jinja2、原生JavaScript和CSS，不引入独立前端工程；
- 提供表格链接和阶段名称输入；
- 提交期间禁用重复操作并展示加载状态；
- 展示项目、阶段、截止时间、待催人数、未填项数和异常数；
- 按责任人展示姓名、脱敏邮箱和业务领域；
- 异常清单显示行号、业务领域和可理解的中文原因；
- 预览只读，不允许勾选、编辑、增删接收人；
- 二次确认弹窗明确发送人数、异常数和“发送后不可撤回”；
- 发送期间轮询结果，完成后停止；
- 部分失败时显示“仅重试失败项”；
- 快照过期时引导重新预览；
- 零待催项时禁用发送按钮。

### 3.2 安全与网关

- 应用只允许通过公司内网网关访问；
- 网关负责HTTPS、统一鉴权和基础访问日志；
- 增加CSRF防护、允许域名校验和接口限流；
- App Secret和Redis凭证通过容器Secret或公司密钥系统注入；
- 禁止应用直接暴露公网端口；
- 检查源码、镜像、日志和前端响应中不存在密钥或完整身份信息。

### 3.3 可观测性

- 输出结构化日志并包含请求链路ID和 `previewId`；
- 记录预览耗时、行数、接收人数、异常数和发送结果统计；
- 接入预览成功率、发送成功率、飞书限流、Redis错误等指标；
- 配置令牌刷新失败、Redis不可用和发送任务超时告警；
- 日志不记录完整链接、完整邮箱、完整 `open_id`、完整消息正文或TPM身份。

### 3.4 容器与部署

- 完善Dockerfile和生产启动参数；
- 完善Redis连接、健康检查和优雅关闭；
- 验证至少两个应用实例共享Redis时的幂等性；
- 提供环境变量清单、部署步骤、回滚步骤和故障排查说明；
- 在公司内网环境完成冒烟验证。

### 3.5 最终验收

- 按冻结方案执行核心功能、异常、并发、安全和性能用例；
- 验证300行业务规模；
- 验证真实消息卡片内容和打开表格按钮；
- 验证刷新、双击、并发和重试不造成重复发送；
- 完成一期范围和非目标复核；
- 形成最终验收记录和已知限制列表。

## 4. 测试范围

- 页面输入校验、加载、预览、确认、进度和结果状态测试；
- 零待催、行级异常、结构错误和快照过期页面测试；
- CSRF、域名白名单、接口限流和脱敏测试；
- Docker镜像构建与启动测试；
- Redis不可用和飞书接口异常下的就绪检查测试；
- 双实例幂等和进程重启恢复测试；
- 300行解析性能和最多300名接收人编排测试；
- 完整端到端验收测试。

## 5. 阶段交付物

- 可用的TPM简易操作页面；
- 完整结构化日志、指标和告警配置；
- 可部署Docker镜像及部署配置；
- 部署、回滚和故障排查文档；
- 最终测试与验收报告；
- 阶段工作日志。

## 6. 完成标准

满足以下条件才能结束阶段3并认定一期完成：

1. TPM可在内网页面完成输入、预览、确认、发送和失败重试；
2. 页面严格只读预览，不允许改变发送范围；
3. Docker环境可启动并通过存活、就绪检查；
4. 多实例下不发生重复发送；
5. 日志、指标和告警满足冻结方案要求；
6. 源码、日志、页面和镜像均不泄露密钥及完整身份信息；
7. 冻结方案中的一期核心验收用例全部通过；
8. 部署、回滚、验收和工作日志完整。

## 7. 本阶段禁止事项

- 不增加定时任务或自动发送；
- 不支持多阶段同时扫描；
- 不支持多维表格、问卷、群组或外部联系人；
- 不增加预览编辑或选择性发送；
- 不新增业务数据库或历史管理后台；
- 不以“上线优化”为由改变冻结业务规则。

实施阶段3时，在 `docs/work_logs/` 新建：

```text

```

日志至少记录：日期、前置验收、页面和部署改动、配置变更、执行命令、测试与验收结果、安全检查、上线或回滚信息、已知限制和最终结论。不得记录任何真实密钥或完整个人标识。
